TR-25 BILL GENERATOR v2 – Android
- Offline PIN login (with recovery word)
- Month-wise tour diary: add / edit / delete journeys with Purpose and Remarks
- Data stored on the phone; Backup / Restore to a file
- Export: Print / Save PDF, Word (.doc, editable), Excel (.csv)
The app is app/src/main/assets/index.html inside a WebView.
GitHub Actions builds the APK on every push (Actions tab -> latest run -> Artifacts).
